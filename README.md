# 우리 집 알뜰 식탁 🍚

성인 2명을 위한 **일주일 식단 + 장보기 + 실제 구매금액 가계부** 웹앱입니다.

- 식단·장보기 앱: https://hyogiman.github.io/Meal/ (GitHub Pages 최초 활성화가 필요할 수 있습니다)
- HTML 소스: [index.html](./index.html)
- 식비 목표: 성인 2명, 일주일 **80,000원**
- 이번 식단의 예상 장보기 전체 금액: **78,300원** (기본 양념 보유 및 실속·할인가 가정)

## 이번 장보기: 3단계로 사용하세요

### 1. 🏠 집에 있는 재료 확인

**체크한 식재료는 '집에 있음'이라는 뜻이고 구매 목록에서 빠집니다.** 체크하지 않은 재료만 다음 단계에서 구매할 품목으로 보입니다. 기존 체크 상태는 최초 적용할 때 한 번 가져오고, 이후에는 **주간별로 별도 관리**합니다.

### 2. 🛒 실제 구매 + 가격 입력

마트에서 실제로 구매한 품목의 **실제 결제금액**을 입력하고 **구매 완료**를 누릅니다.

- 구매 완료 시 해당 품목이 미구매 목록에서 구매 완료 목록으로 이동하며, 실제 금액은 기존 가계부에 **즉시 한 번만 기록**됩니다.
- 한 품목의 금액을 다시 수정하거나, 잘못 저장한 구매를 취소할 수 있습니다.
- 이번 주 사지 않기로 한 품목은 **이번 주 안 삼**으로 옮길 수 있습니다. 이는 실제 지출로 집계되지 않습니다.
- 목록에 없는 품목도 **계획에 없던 추가 구매 기록**으로 입력할 수 있습니다.
- 기존 **📒 지출 내역**에 똑같은 이름으로 기록된 항목은 **기존 지출 연결**을 눌러 새 지출을 생성하지 않고 연결할 수 있습니다. 연결만 취소해도 기존 기록은 삭제되지 않습니다.

### 3. ✅ 장보기 정산

재고로 제외한 품목 수, 구매 완료한 품목, **이번 주 기록된 실제 지출**, 남은 예산, 아직 사지 않은 물건을 함께 확인합니다. **이 주 장보기 완료**로 정산 상태를 표시할 수 있으며, 이후에도 **정산 다시 열기**로 내역을 수정할 수 있습니다.

주간 기준은 **월요일~일요일**이며 이전 주·다음 주로 이동해 해당 주의 체크와 구매 상태를 별도로 확인할 수 있습니다.

## 가계부와 데이터 보관

- **📒 지출 내역** 탭에서 날짜별 구매 기록, 주간 80,000원 예산 대비 실제 사용 금액, 월간 누계, 분류별 지출을 확인합니다.
- 저장된 구매 기록의 금액·메모·구매처를 수정하거나, 구매 기록을 삭제할 수 있습니다.
- 내역 전체를 **CSV**로 내려받거나 **JSON으로 백업 및 복원**할 수 있습니다.
- **중요:** 구매 목록·가계부는 기기/브라우저 **localStorage**에만 저장됩니다. 이 공개 GitHub 저장소에 실제 구매 내역이 업로드되지 않고, 기기 간 자동 동기화되지 않습니다. 브라우저 데이터 삭제에 대비해 JSON 백업을 권장합니다.
- **예상액과 실제 지출을 혼동하지 마세요:** 예상 장보기 비용은 아직 사야 할 물건의 목표가격 합계이고, 실제 지출은 사용자가 입력한 결제금액 합계입니다. 기록하지 않은 지출은 자동으로 파악할 수 없습니다.

## 최초 1회 GitHub Pages 설정

1. [Meal Pages 설정](https://github.com/hyogiman/Meal/settings/pages)에 들어갑니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 선택하고 저장합니다.
4. 게시 완료 후 https://hyogiman.github.io/Meal/ 에서 이용할 수 있습니다.

이후에는 같은 주소를 유지하고 `main/index.html`을 갱신하는 방식으로 수정합니다.
