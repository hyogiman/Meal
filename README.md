# 우리 집 알뜰 식탁 🍚

성인 2명이 주 8만 원 예산 안에서 다양한 음식을 먹을 수 있도록 구성한 **7일 식단표·레시피 웹앱**입니다.

**식단표 주소 (GitHub Pages 활성화 후):** https://hyogiman.github.io/Meal/

## 현재 구성

- 성인 2명, 7일, 21끼의 메뉴 및 상세 조리법
- 목표 장보기 비용: **78,300원** (할인상품 구매, 기본 양념 보유 가정 / 실제 가격은 변동)
- 카레, 고등어조림, 닭간장찜, 두부덮밥, 돼지불고기, 비빔국수, 잔치국수 등
- 요일 전환, 장보기 체크와 예산 계산, 인쇄, 모바일 대응
- 별도 서버 없는 단일 `index.html`

## 최초 1회 GitHub Pages 설정

1. [저장소 Pages 설정](https://github.com/hyogiman/Meal/settings/pages)으로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. **Branch**에 `main`, 폴더에 `/(root)`를 고른 뒤 **Save**를 누릅니다.
4. 사이트가 게시되면 https://hyogiman.github.io/Meal/ 주소를 휴대폰 홈화면에 추가해 이용할 수 있습니다.

이후 `main/index.html`을 수정하면 **같은 웹주소**에 자동으로 반영됩니다.

## 유지관리

- 식단·레시피·예산·디자인 수정 요청을 받을 때 현재 `index.html`을 업데이트합니다.
- 장보기 체크 상태는 각 기기의 `localStorage`에 저장되며 **기기 간 자동 동기화는 되지 않습니다**.
- 리포지토리와 Pages는 공개 상태이므로 개인정보·실제 가계부 데이터는 게시하지 않습니다.


## 장보기 가계부 (실제 지출 기록)

웹앱의 **💰 장보기 가계부** 탭에서 구매한 물품의 날짜, 품목, 분류, **실제 결제금액**, 구매처, 수량·메모를 기록할 수 있습니다.

- **주간 예산 80,000원**에서 실제 지출을 차감해 잔액과 초과 지출을 표시합니다. 이전 주·다음 주를 넘겨 기록을 확인할 수 있습니다.
- **이번 달 누계**와 선택한 주의 **분류별 실제 지출**을 볼 수 있습니다.
- **장보기 목록 → + 실제 지출** 버튼은 품목 이름만 가져옵니다. 예상 가격은 실제 지출로 자동 입력되지 않습니다.
- 기록한 내역을 수정하거나 삭제할 수 있습니다.
- **CSV 내보내기**로 엑셀에서 열 수 있습니다.
- **JSON 백업/복원**으로 데이터를 수동으로 옮길 수 있습니다. 복원 시 기존 기록은 확인 후 교체합니다.

> **개인정보 보호 및 저장 주의:** 가계부 데이터는 사용자의 **브라우저 localStorage에만** 남습니다. GitHub에 업로드되지 않으며, 다른 기기나 브라우저로 자동 동기화되지 않습니다. 브라우저 데이터 삭제 또는 기기 교체 시 기록이 없어질 수 있으니 JSON 백업을 주기적으로 보관하세요. GitHub Pages는 공개 웹앱이지만, 입력한 지출 정보는 저장소의 코드에 포함되지 않습니다.
