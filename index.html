🥬 먼저 소비할 것

  1. 시금치는 월요일 아침 국에 사용합니다.
  2. 청경채는 월요일 볶음과 수요일 볶음밥에 우선 사용합니다.
  3. 콩나물은 월요일 약 200g부터 사용하고 남은 것은 최대한 일찍 충분히 가열하여 먹습니다.
  4. 우유와 바나나는 개봉 후 보관 안내에 따릅니다.

🥩 단백질 분할

  1. 닭다리살 600g → 월요일 300g + 목요일 카레 300g
  2. 돼지고기 500g → 수요일 250g + 토요일 250g
  3. 고등어 550g → 화요일 300g + 금요일 250g
  4. 나중에 먹을 고기·생선은 구매 후 소분 냉동하고 냉장해동하세요.

🥚 보유품 활용

  1. 달걀 10개 → 월 2, 수 2, 목 2, 일 4개
  2. 참치 5캔 → 월·수·토·일 각 1캔, 여유 1캔
  3. 만두 500g → 화요일 250g + 일요일 250g
