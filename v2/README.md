# Meal 2.0 — Firebase 시작 안내

새 주소: https://hyogiman.github.io/Meal/v2/
기존 Meal 식단: https://hyogiman.github.io/Meal/
프로젝트: mealplan-786a6

## Firebase 연결: 최초 1회만 설정

### 1. Google 인증 사용
- Firebase 콘솔: https://console.firebase.google.com/project/mealplan-786a6/authentication/providers
- Authentication → Sign-in method → Google 사용 설정 및 지원 이메일 선택 후 저장
- Authentication → Settings → Authorized domains에 hyogiman.github.io 추가

### 2. Cloud Firestore 데이터베이스 생성
- https://console.firebase.google.com/project/mealplan-786a6/firestore
- 데이터베이스가 없다면 생산/프로덕션 모드로 생성하고 리전 선택
- Firestore → Rules 탭에서 저장소의 firestore.rules 전체를 복사해서 붙여넣고 게시
- 규칙 파일을 GitHub에 올렸다고 실제 규칙이 자동 적용되는 것은 아닙니다.
- 로그아웃 사용자와 다른 사용자 uid 접근은 거부되고, 본인 uid 아래의 데이터만 허용됩니다.

### 3. 동기화 확인
- 새 주소를 열어 Google 로그인
- 연결 상태가 'Firebase 동기화 연결됨'인지 확인
- 재고 1개 저장한 뒤 새로고침해 남아 있는지 확인
- 동일 Google 계정으로 다른 기기에서 접속해 확인

## 현재 동작하는 Meal 2.0 기능

### 상세 냉장고 관리
- 종류, 상품명, 수량과 단위(g/kg, 개, 팩 등), 냉장·냉동·실온, 구입일, 소비기한, 개봉 여부, 메모
- 같은 음식도 구매시기/소비기한이 다르면 별도 묶음으로 등록
- 실제 양을 모르면 '수량 미확인'으로 기록하고 임의 숫자 입력 금지
- '사용'을 누르면 실제 먹은 양만 차감. 식단 추천 자체로 자동 차감 안 함
- 과거에 알려주신 쌀·달걀·대파·양파·양배추·시금치·청경채·참치캔·김·만두·미역·다시마·카레가루·김치 14종은 버튼을 눌러 불러올 수 있습니다. 수량 불명 항목은 빈 값으로 유지됩니다.

### 장보기/실결제 기록
- 구매 예정 상품과 실제 구매를 구분
- 2026-11-01 제공한 쿠팡 캡처 속 14개 상품, 표시가격 합계 66,420원은 버튼을 눌러 '구매 예정'으로 불러오기
- '구매 완료'를 누르기 전까지 가계부 지출 및 냉장고 재고로 집계하지 않음
- 실제 결제수량과 실결제가를 확인한 뒤, 재고 1묶음과 구매 기록을 동시에 추가
- 주간·월간 실지출 집계, 80,000원 기본 주간 예산 (사용자가 변경할 수 있으며 Firebase에 설정 동기화)

### 현실적 상차림
- 현재는 AI가 아닌 내장된 28개 한국 가정식 레시피 기반의 로컬 규칙 추천
- 7일 × 3끼 구성. 밥·김치만 준비된 것으로 가정
- 국/나물/무침이 따로 생겨난다고 가정하지 않음. 조리해야 한다면 그 자체가 오늘의 조리 메뉴 또는 명시된 추가 조리로 포함
- 2인분 재료 수량, 양념(간장/고춧가루/설탕/마늘 등의 배합), 단계별 조리법, 총 조리시간(밥 취사 및 설거지는 별도) 표시
- 재고 부족과 수량 미확인 구분, 추가 구매 필요량 목록 제공
- 필요한 경우 구매 예정 상품도 선택적으로 식단 후보에 포함 가능. 실제로 샀다고 간주하지 않음
- 원하는 한 끼만 다른 메뉴로 바꾸고 추가 재료를 재계산해 저장 가능
- 주말에 다음 주 식단 준비 카드 표시

## 데이터와 개인정보

브라우저 로컬 체험은 이 기기의 localStorage에 저장되며 사용자가 삭제하면 사라질 수 있습니다.
Google 로그인 후에는 사용자 uid에 제한된 Firestore 경로에 저장합니다.
가족 계정 공유는 현재 제공하지 않습니다.
저장소의 Firebase 웹 구성값은 클라이언트 설정값일 뿐 백엔드 관리자 자격증명이 아닙니다.
보안은 배포된 Firestore Security Rules로 통제합니다.
